# Mirror information

This repository is a clean source snapshot of the HiredToday mini-program project hosted at [Gitee](https://gitee.com/ant-warrior-front-end/hired-today). The Gitee repository remains the upstream source.

The upstream commit history is available at [Gitee commits](https://gitee.com/ant-warrior-front-end/hired-today/commits/master). The source checkout had 74 commits, 72 attributed to Yan Yulin. This GitHub mirror intentionally starts with a clean snapshot rather than importing commit metadata.

The project is hosted under the ant-warrior-front-end team on Gitee; this mirror does not claim sole project ownership. The LICENSE file is preserved from the upstream repository.
